Dictate for Windows — Beta 1 is the first consolidated Windows beta release.

- Clean, responsive Windows interface for compact windows and 27-inch 1440p displays.
- NVIDIA Parakeet downloads automatically during first setup and remains replaceable with local Whisper models.
- A more responsive rounded waveform and recovery Copy/Dismiss controls in the floating recorder.
- Smoother History and Dictionary interactions, aligned model status columns, and Windows-native Segoe UI Variable typography.
- Microsoft Store builds check for signed Store updates in Settings, install them through Windows, and restart after completion.

The Microsoft Store submission uses package identity `PriyanshSingh.Dictate-PrivateVoiceTyping` and package version `1.1.9.0`. The GitHub EXE remains an unsigned fallback and links back to the download page for future builds.
