# Generation prompt — final UI

Built with the built-in ImageGen tool as a high-fidelity `ui-mockup` using Quiet
Ribbon, Color Index, and Focus Deck as component references.

The board was instructed to preserve Color Index's History, palette, date navigation,
and Dictionary character; use Focus Deck's Dictionary list/editor efficiency; use
Quiet Ribbon's calm Settings controls; and replace the recorder with the compact
Signal Pebble. The final revision added a persistent, low-prominence `Dictate ready`
state with no idle waveform or microphone-capture implication, plus coordinated
listening, processing, inserted, and recovery states in light and dark.

Hard constraints included: one visual identity, no sidebar, no notetaker/meeting
features, no transcript inside the overlay, no competitor branding, no decorative
gradient, and no oversized recorder pill.
