# Final Dictate Design

This directory contains the approved, single implementation direction.

- `dictate-final-ui.png` — Color Index application surfaces, light/dark Settings, and
  the complete Signal Pebble state system.
- `dictate-brand-system.png` — the approved D + insertion cursor + signal identity,
  app-icon direction, wordmark, and monochrome menu-bar glyph.

Implementation authority and details live in `../../DESIGN.md`. The ready-to-paste
builder prompt is `../../PROMPT_GPT_5_6_LUNA_UI.md`.

The boards are composition and identity references. Their generated sample content is
not product data, and the brand sheet is not a substitute for production vector icon
assets.
