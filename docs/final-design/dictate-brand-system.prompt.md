# Generation prompt — brand system

Built with the built-in ImageGen tool as a `logo-brand` reference using the final UI
board for visual continuity.

The mark was instructed to combine a capital `D`, a text insertion cursor in negative
space, and three or four compact signal bars so it communicates voice becoming
inserted text. The same single identity had to work as a macOS app icon, Dictate
wordmark, monochrome 16–18 point menu-bar glyph, window-title mark, and Signal Pebble
mark in light and dark.

Hard constraints included: one final mark only; no Apple logo; no competitor logo;
no microphone pictogram, speech bubble, or generic waveform circle; no invented
company name; and a core silhouette that remains legible in one color.
