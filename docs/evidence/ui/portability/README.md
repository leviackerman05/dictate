Browser-rendered captures from the local Dictate code, 2026-09-08. Website images
use the built Astro site. Portable images use the real TypeScript/CSS renderer
with a mocked Tauri bridge and synthetic text; they are not native-device tests.
No private transcripts, generated artwork, or third-party photographs are used.
Capture workflow: `Desktop/scripts/check-ui.cjs`. Desktop viewport 1120×780;
minimum portable viewport 760×600; website 1440×1000 and 390×844. Full-page capture
height may exceed the viewport. App icons derive from the existing repository
SVG. These images record this beta and do not replace microphone/editor testing.
